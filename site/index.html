What it does

A desktop app for running a small team of agents, on your Mac, with your keys.

A Chief of Staff first

Tell it about your work. It creates an agent for each part of the job (outreach, writing, research, operations) and hands tasks between them.

Asks before it acts

Reading runs on its own. Anything that changes something waits for you: Refuse, Allow once or Always allow. Sending, deleting and paying always ask.

Each agent, its own model

Pick a model per agent and switch mid-conversation. The agent keeps its job, its memory and the conversation.

Memory you can edit

Agents remember how you like things done, in plain sentences you can read, change or undo.

Routines in plain words

"Every weekday at 8am, brief me." Agents run on a schedule while Mystic is open.

Your folder, your Mac

Agents, chats, memory and notes are plain files in ~/Mystic. Keys stay in your Mac's keychain.

Any key you bring

Add as many as you like. Keys go only to the provider they belong to.

Install

Two ways. Both install the same signed release from GitHub.

The one-line install

Open Terminal and paste:

curl -fsSL https://earth-care-network.github.io/mystic/install.sh | sh

It downloads the latest release, checks it against its published checksum, and puts Mystic in Applications. Read the script.

The download

  1. Open Mystic.dmg and drag Mystic to Applications.
  2. Open Mystic. The first time, macOS may say it can't check the app: Mystic isn't notarized by Apple yet.
  3. Open System Settings › Privacy & Security, scroll down and click Open Anyway.

The one-line install skips that step.

Mystic checks for a new signed version when it starts and installs it when you say so. Windows and Linux builds: all downloads.

Questions

Is it really free?

Yes. Mystic is MIT licensed. You pay your model provider for what you use, or nothing with a model on your Mac. Earth Care Cloud is part of an enterprise's Pro plan on Earth Care Network.

Where do my keys go?

Into your Mac's keychain, and only to the provider they belong to. They are never written to a file, never sent to Earth Care Network.

Can an agent send an email or post without me?

No. Sending, posting, paying, signing and deleting always ask, every time. Other changes ask once unless you choose Always allow.

Why does macOS warn me the first time?

Apple's notarization isn't set up for Mystic yet. The download is signed for updates and checked against a published checksum; the one-line install opens without the warning.

Built on what?

Tauri, React and TypeScript, with the approval gate, tenant-package format and AG-UI events of CopilotKit's open-source OpenDuet. You can export your team as an OpenDuet package.

How do I help?

Read CONTRIBUTING.md and open an issue. Security problems go privately to a security advisory.
